# mod_edelta_dunare

Danube water level and water temperature widget for Joomla (chart / table / both).

- No API key required (public api.edelta.ro endpoints).
- Public data is limited to the latest 30 days; requesting more shows a
  "more data on edelta.ro" link (configurable `more_url`).
- Server-side fetch + cache; Chart.js bundled locally.
- Joomla 4 / 5 / 6. Languages: en-GB, ro-RO, de-DE, ru-RU.

See the project README for install and configuration: https://github.com/reflexie/edelta-danube
