# edelta-danube

Free, open-source extensions to display **Danube water levels and water temperature**
on your website, powered by the public API at [api.edelta.ro](https://api.edelta.ro).

Data covers the Romanian sector of the Danube and the Danube Delta ports
(Sulina, Tulcea, Isaccea, Galați, Brăila, Hârșova, Cernavodă, Călărași, Oltenița,
Giurgiu, Zimnicea, Turnu Măgurele, Corabia, Bechet, Rast, Calafat, Cetate, Gruia,
Turnu Severin, Orșova, Drencova, Moldova Veche, Băile Herculane, Baziaș).

## Components

| Folder     | Type                | Description                                           |
|------------|---------------------|-------------------------------------------------------|
| `joomla/`  | Joomla module       | `mod_edelta_dunare` — chart and/or table widget       |
| `wordpress/` | WordPress plugin  | _planned_                                            |
| `api/`     | API integration     | Public endpoint spec + rate limiting for api.edelta.ro |
